# Estibordo Navigator

Chartplotter para Windows baseado no OpenCPN, com identidade visual e fluxo próprios.

Base upstream:
- OpenCPN/OpenCPN
- OpenCPN/plugins
- OpenCPN/opencpn-libs

Objetivo: preservar cartas, GPS/NMEA, AIS, rotas, waypoints, tracks, OpenGL e plugins, aplicando uma interface própria para Windows.

Setup Windows:
1. Abra PowerShell na raiz do projeto.
2. Execute scripts/bootstrap.ps1
3. Execute scripts/apply-customization.ps1
4. Execute scripts/build-windows.ps1
